# 浏览器 session(Cookie)

给每个浏览器一个稳定身份,用于桶锁归属和冲突提示。第一次初始化时生成,之后不再改变。

## 存储

| 项 | 值 |
| --- | --- |
| 位置 | Cookie |
| 名称 | `keymaster.session` |
| 值 | `<session id>`,32 位小写 hex 随机数 |
| 属性 | `Path=/`、`Expires` 设为远期(永久)、`SameSite=Lax`;HTTPS 下加 `Secure` |

- **不是 `HttpOnly`**:页面需要读取它;它不是凭据,拿到它也不能解密任何数据。
- 不放任何用户数据:没有公钥、没有密码、没有设备引导内容。

## 生成与生命周期

- 本浏览器**第一次完成初始化**(写入 device-bootstrap)时生成并写入 cookie;
- 之后永不改变:刷新、锁钱包、重启浏览器都是同一个值;
- cookie 被清除 = 视为一台“新浏览器”,下次初始化时重新生成;
- 校验:值必须匹配 `^[0-9a-f]{32}$`;缺失或非法按新浏览器处理。

## 用途

- 作为**桶锁**的持有者标识(见《桶锁》),让桶知道“现在是谁在用”;
- 多标签页共享同一个值,天然算同一个持有者;
- 用于提示与诊断:“桶正被另一个浏览器使用”。
