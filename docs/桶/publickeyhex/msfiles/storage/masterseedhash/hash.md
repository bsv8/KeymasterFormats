# `桶/<owner 公钥>/msfiles/storage/<seedhash>/<块 hash>` — MasterSeed 文件块

源文件按 256 KiB 切分后每个块的原始字节；文件名就是这一块内容的 SHA-256。一个种子的全部块
聚在 `storage/<seedhash>/` 目录下，块的顺序由种子文件定义。

## 位置与命名

```
桶根/<owner 公钥>/msfiles/storage/<seedhash>/<块 hash>
```

| 部分 | 规则 |
| --- | --- |
| `<owner 公钥>` | 当前 active key 的压缩公钥，小写 |
| `msfiles/storage` | 固定目录 |
| `<seedhash>` | 对应种子的 MasterSeed `seed_hash`，64 位小写 hex，作目录名 |
| `<块 hash>` | 块内容的 SHA-256，64 位小写 hex，无后缀 |

- 目录名把块归属到某个种子；同一内容出现在多个种子下时，各自目录各存一份，不共享文件。
- 块顺序与最后块长度不在文件名里：顺序来自种子文件，最后块长度来自源文件大小。

## 文件内容

内容就是源文件在该位置的原始块字节，不加头、不压缩、不加密：

- 除最后一个块外，每个块恰好 `262144` 字节（256 KiB，不是 256000 字节）；
- 最后一个块为 `1 ~ 262144` 字节；
- 空文件的种子没有任何块，`storage/<seedhash>/` 目录为空或不存在；
- `blockHash = SHA256(块字节)`，其 64 位小写 hex 即文件名。

## 规则

- **写入**：在种子文件之前写入；同一个 `<块 hash>` 在同一目录下重复写入等价于覆盖同内容，
  允许直接覆盖，不需要条件写。
- **去重**：同一源文件内出现多个相同块时只存一个文件；种子文件中的摘要位置照常重复。
- **不修改**：块内容寻址，文件写入后不再改写。
- **缺失**：种子存在但某个按序摘要找不到对应文件，视为文件不完整；不提供下载/预览，
  只允许重传补齐或删除。
- **删除**：随所属种子一起删除：先删种子与元数据，再列 `storage/<seedhash>/` 前缀删除全部块；
  中断不会影响其它种子。
- **并发**：不同块是不同文件，可并行写；同一文件在 Worker 内串行，跨设备最后写入者胜
  （见《存储规则》）。

## 校验规则

1. 文件名匹配 `^[0-9a-f]{64}$`。
2. 对文件字节计算 SHA-256，结果必须等于文件名；不等按损坏处理并中止组装。
3. 长度必须 `<= 262144`；若该位置不是最后一个块，必须恰好等于 `262144`。
   位置与最后块长度由 [种子文件](../../seeds/masterseedhash.md) 的摘要顺序和
   [元数据](../../meta/seedhash.json.md) 的 `fileSizeBytes` 共同确定。
4. 组装完整的原文件后，字节数必须等于元数据的 `fileSizeBytes`；种子文件本身的 SHA-256
   必须等于目录名 `<seedhash>`。

## 设计取舍（消融记录）

- **一内容一对象**：块是远程读取、Range 播放和单独校验的最小单位；同名覆盖天然幂等。
- **按种子分目录**：删除一个种子只需列一个前缀，读取归属明确；代价是相同块在不同种子下
  各存一份，用去重换隔离与删除简单。
- **允许覆盖而不是 CAS**：块内容寻址，同名必同内容，覆盖是幂等的；避免为重复上传增加分支。
- **不存块列表**：顺序、数量与偏移都由种子文件和源文件大小唯一决定，不重复保存。
- **不存块偏移**：偏移就是 `序号 × 262144`，最后块长度由 `fileSizeBytes` 算出。

## 完整示例

沿用官方测试向量 UTF-8 `abc`：

```text
源文件大小    3
块数          1
块摘要 hex    ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
seed_hash     4f8b42c22dd3729b519ba6f68d2da7cc5b2d606d05daed5ad5128cc03e6c6358
```

路径：

```
桶/<owner 公钥>/msfiles/storage/4f8b42c22dd3729b519ba6f68d2da7cc5b2d606d05daed5ad5128cc03e6c6358/ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

文件内容是这 3 个字节 `616263`；写成 hex 只是为了展示。对应的种子文件见
[seeds/masterseedhash.md](../../seeds/masterseedhash.md)。
